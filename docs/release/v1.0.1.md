# v1.0.1 release verification

A CI-configuration fix and a correction to the `v1.0.0` record. **No application code changed** —
`src/`, `migrations/`, `tests/`, and `benchmarks/` are byte-identical to `v1.0.0`, so every
measurement in [docs/release/v1.0.0.md](./v1.0.0.md) still describes this release. This document
records only what is new: a green CI run.

## Why this release exists

`v1.0.0` was tagged on a commit whose CI run was red, and its release record wrongly claimed
otherwise. The failure was in the workflow, not the product: `TEST_DATABASE_URL` pointed all eight
integration test files at one shared database while vitest ran them in parallel, so they deadlocked
on concurrent DDL (`40P01`, `AccessExclusiveLock on relation`) and read each other's rows. The
variable is now unset, and Testcontainers gives each file its own PostgreSQL exactly as it does
locally.

The `v1.0.0` tag was deliberately left where it is; see
[its CI status section](./v1.0.0.md#ci-status).
